# AWS Architecture Advisor

AI-Powered AWS Architecture Advisor & Deployment Platform for AmalitechTraining students.

## What It Does

Students describe the architecture they want to build in natural language. The platform:

1. **Designs** the architecture using Amazon Bedrock with RAG over the AWS Well-Architected Framework
2. **Visualizes** it as an interactive diagram with official AWS architecture icons
3. **Reviews** it against all six Well-Architected pillars with cited recommendations
4. **Generates** production-ready CloudFormation templates (deterministic code transforms, not LLM-generated)
5. **Validates** templates through 4 layers: cfn-lint, cfn-nag, AWS ValidateTemplate API, and human review
6. **Estimates** costs using real AWS Pricing API data
7. **Deploys** to the student's AWS account with budget gates and automatic cleanup

## Architecture

Fully serverless on AWS:

- **Frontend:** React + Vite SPA on S3 + CloudFront
- **Backend:** API Gateway (REST + WebSocket) + Lambda (Node.js 20, ARM64)
- **Database:** DynamoDB (on-demand, multi-table)
- **AI:** Amazon Bedrock + Bedrock Knowledge Bases (S3 vector index)
- **Auth:** Amazon Cognito with trainer/student roles
- **IaC:** CloudFormation (generated by deterministic code, never by the LLM)

Estimated platform cost: ~$20-32/month at 50 students.

## Quick Start

```bash
# Prerequisites: Node.js 20+, AWS CLI configured, AWS SAM CLI
npm install
npm run dev:frontend    # http://localhost:3000
npm run dev:backend     # SAM local API
```

## Project Structure

```
frontend/     React SPA (Vite, Amplify UI, D3.js diagrams)
backend/      Lambda functions grouped by domain
shared/       TypeScript types, JSON schemas, constants
infra/        CloudFormation stacks
docs/         API spec, architecture decisions
scripts/      Build and validation scripts
```

## Key Design Principles

1. **Architecture model is the single source of truth** — one JSON object drives diagram, CFN template, cost estimate, and WA review
2. **CFN templates are deterministic code transforms** — the LLM designs; tested code writes CloudFormation
3. **RAG over Well-Architected Framework** — recommendations cite real AWS docs, not LLM memory
4. **Budget gate before every deployment** — no surprise bills
5. **Freemium model** — 3 projects free, then trainer unlock
